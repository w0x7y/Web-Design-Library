# Web Library

A website starter built with React, TypeScript, Vite, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Start editing `src/App.tsx` and use
Tailwind utility classes to style your components. Global styles live in
`src/index.css`.

## Checks and production build

```bash
npm run lint
npm run build
npm run preview
```

The production build is written to `dist/`. The preview command serves that
build locally.

Tailwind is configured with the official Vite plugin:
https://tailwindcss.com/docs/installation/using-vite
